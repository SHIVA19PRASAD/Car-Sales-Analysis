# Car-Sales-Analysis
Overview :
Built an interactive Power BI dashboard analyzing 24K+ car sales records to track sales performance, pricing trends, and regional demand patterns.

Key Highlights :
Developed YTD, MTD, YOY KPIs using DAX
Identified 23.59% YoY growth in sales
Analyzed weekly trends, regional performance, and product distribution
Created dynamic visualizations and detailed reporting dashboards

Insights :
Significant year-over-year sales growth (23.59%)
High sales concentration in specific regions and vehicle categories
Clear pricing and demand patterns across customer segments

Tools Used :
Power BI, DAX Functions, Power Query and Data Modeling

Outcome :
Delivered a data-driven dashboard enabling analysis of sales trends, performance tracking, and business decision-making.
